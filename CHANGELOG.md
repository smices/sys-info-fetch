# Changelog

## 0.2.0 - 2026-07-29

- Migrated the implementation to Nim.
- Added Neofetch-compatible text, JSON, configuration, ASCII logo, and bar modes.
- Added bundled official Neofetch distro logos and ANSI color remapping.
- Added macOS, Linux, and BSD collector branches.
- Added CPU, GPU, memory, disk, and external USB/Thunderbolt/Bluetooth hardware details.
- Added native build output under `release/` and the latest local binary under `bin/`.
